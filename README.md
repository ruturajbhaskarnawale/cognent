# Agency Platform

## Overview
High-performance agency website/platform.

## Stack
- **Frontend**: Next.js 14, Tailwind, Framer Motion
- **Backend**: FastAPI, PostgreSQL

## Setup

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```
